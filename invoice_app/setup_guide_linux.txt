====================================================
　請求書かんたん作成ツール　セットアップ手順
　　　　　　　　　　　　　　　　　（Linux用）
====================================================

このツールは、パソコンの操作に慣れていない方でも
かんたんに請求書PDFを作れるように作られています。
最初の準備だけ少し手間がかかりますが、一度準備してしまえば
あとは「アイコンをダブルクリックするだけ」で使えます。

（Windows用の手順は setup_guide.txt をご覧ください）

分からないところがあれば、遠慮なく用意した人に聞いてください。


----------------------------------------------------
【準備するもの】
----------------------------------------------------
・このフォルダ一式（invoice_generator.py などが入ったフォルダ）
・インターネットにつながっているパソコン（Linux）
・（できれば）会社の印鑑（ハンコ）の画像ファイル
   ※ スマートフォンで印鑑を紙に押して撮影し、
     画像として保存したものでも構いません。
     あとから設定することもできるので、今はなくても大丈夫です。


----------------------------------------------------
【手順 1】必要なソフトを入れる（最初の1回だけ）
----------------------------------------------------
ターミナル（端末）を開いて、次のコマンドを実行してください。
お使いのディストリビューションに合わせて選んでください。

  Ubuntu / Debian系：
      sudo apt install python3 python3-venv python3-tk

  Fedora系：
      sudo dnf install python3 python3-tkinter

  Arch系：
      sudo pacman -S python tk

パスワードの入力を求められたら、パソコンのログインパスワードを
入力してください（画面には表示されませんが入力はされています）。


----------------------------------------------------
【手順 2】初回セットアップを実行する
----------------------------------------------------
ターミナルで、このフォルダに移動してから次を実行してください。

    cd フォルダのパス
    bash 01_setup.sh

いろいろな文字が流れますが、何も操作せずにそのまま待っていてください。

「セットアップ完了！」と表示されたら成功です。
Enterキーを押すと画面が閉じます。

このとき、デスクトップ（またはアプリ一覧）に
「請求書かんたん作成ツール」のアイコンが自動的に作られます。
次回からは、このアイコンをダブルクリックするだけでツールを開けます。
（デスクトップ環境によっては、アイコンを初めてダブルクリックしたときに
 「信頼して実行しますか？」のような確認が出ることがあります。
 その場合は「実行」や「信頼する」を選んでください）

　※ もし途中でエラーが表示された場合は、
    インターネットにつながっているかを確認して、
    もう一度「bash 01_setup.sh」を実行してください。


----------------------------------------------------
【手順 3】ツールを起動して使ってみる
----------------------------------------------------
デスクトップ（またはアプリ一覧）の
「請求書かんたん作成ツール」アイコンをダブルクリックします。
（見つからない場合は、ターミナルでこのフォルダに移動して
  「bash 02_start_invoice_tool.sh」を実行してください）

しばらくすると、請求書を入力する画面が開きます。

画面の中の「？ 使い方ヘルプ」ボタンを押すと、
使い方の説明がいつでも読めます。困ったときはここを見てください。

かんたんな流れ：
  ① 宛先（請求する相手）を入力する
  ② 会社印の画像を設定する（初回のみ。次回から自動で使われます）
  ③ 品目（内容・数量・単価）を入力する
      → 金額と合計は自動で計算されます
  ④ 一番下の「請求書PDFを作成する」ボタンを押す
  ⑤ 保存する場所（デスクトップなど）を選ぶ
  ⑥ 完成したPDFを開いて確認する


----------------------------------------------------
【よくあるトラブル】
----------------------------------------------------
Q. 「bash: python3: command not found」と出る。
A. 手順1がまだ行われていません。ターミナルで
   お使いの環境に合ったコマンドを実行してください。

Q. 「tkinter が見つかりませんでした」と出る。
A. 画面表示用の部品（python3-tk など）が入っていません。
   手順1のコマンドをもう一度確認して実行してください。

Q. 日本語が四角い記号（□）で表示される。
A. 通常は自動で解消されます（起動時に、同梱の日本語フォントを
   あなたのユーザー専用フォルダ ~/.local/share/fonts に
   自動でコピーする仕組みが入っています）。
   もし直らない場合は、お使いのディストリビューションの
   パッケージ管理ツールで日本語フォント（例：fonts-noto-cjk）を
   追加でインストールしてみてください。

Q. 会社印の画像がうまく重ならない・ずれている。
A. 印影（ハンコ部分）だけが写っている、正方形に近い画像を
   使うときれいに重なりやすいです。
   スマートフォンの写真アプリなどで、ハンコの部分だけを
   四角く切り抜いてから使うのがおすすめです。

Q. その他、動かない・エラーが出る。
A. ツール画面上に出てくるメッセージをそのまま
   スクリーンショット（画面の写真）に撮って、
   用意した人に見せてください。

気楽に触ってみてください。
